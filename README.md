
# K-Means Image Segmentation — Digital Image Processing

A Digital Image Processing project focused on RGB image analysis and color-based image segmentation using K-Means clustering.

## Project Overview

This project explores image segmentation by grouping pixels according to their RGB color characteristics. The complete workflow is implemented in a Jupyter Notebook and includes image preprocessing, pixel-level analysis, K-Means clustering, segmentation visualization, and evaluation of the generated results.

## Objectives

- Analyze RGB image information
- Visualize image color distributions
- Convert image pixels into feature vectors
- Apply K-Means clustering for color-based segmentation
- Visualize clustered and segmented regions
- Analyze the final segmentation results
